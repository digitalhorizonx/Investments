# HorizonX Investments

Investor landing page for the HorizonX Growth Round.

## Purpose

This repository powers the standalone investor experience intended for `invest.horizonx.site`.

## Stack

Static HTML, CSS and JavaScript with no dependency on the production Xability application or backend.

## Deployment

Designed for Vercel static deployment. The production custom domain will be attached only after a successful Vercel deployment and DNS target is confirmed.

## Public positioning

The page presents HorizonX, Xability, the HorizonX Digitalization Index, the product learning loop, current team, market priorities and the proposed growth round. Financial examples are illustrative and subject to final legal documentation.
